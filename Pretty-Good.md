# NoiseNode

## Idea
### App starts with the consumer ("The Average Joe"). They live somewhere in Heilbronn.
### They observe certain "issues" in their neighborhood (be it heat, humidity, noise, weather, etc.).
### Via an app or interface of some kind they can "report" one or multiple of these issues.
### The report is then mapped geographically using gps (wherever the report was made from or it can be manually entered).
### If there is a certain hotspot of reports, so a cluster, it can then run that area through historical data to analyse if it should be analysed (validate it, so "Is this legit?").
### If an area has been verified, perhaps the report also holds some sort of validation of the person (to avoid bots).
### Once fully verified and validated, we send a Sensor pack to a volunteer in the targeted area.
### They then keep the sensor and use it (and are also held liable for its use), and the idea is to "verify the claims in real-time".
### The whole purpose of it is to prove that the "Green City Heilbronn" initiative is actually working by involving the citizens, but also collecting more data because data = Mmmmmmm.

## Potential Issues (technical issues for future concideration)
### Bots (Rate limiting, Human verification of some kind on the reports, we validate high report areas with historical data and then the sensor we send would most definitely verify it).
